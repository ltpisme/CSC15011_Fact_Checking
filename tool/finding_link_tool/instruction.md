## 🛠 Setup Instructions
1. Open `app.py` and locate the `id_ranges` variable.
2. Update `id_ranges` with your specific ID list.
3. Launch the application by running:
   ```bash
   python app.py

# HOW TO USE
* Navigation: Use the <- and -> buttons to switch between Organization IDs.

* Adding Links: 
1. Paste your URL into the input field.
2. Select the appropriate Source.
3. Click SUBMIT to confirm.
* 
Management: 
1. Selected links will be displayed in the table below.
2. You can remove unwanted links using the delete option.
3. Auto-save: Your progress and results are automatically saved to the log file.
