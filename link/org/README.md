## Original Data Files

This directory contains article URLs collected from the source `vnexpress.net`.

- `org_raw.json`  
  Raw data crawled from the source, collected on a daily basis throughout the year 2025.

- `org.json`  
  Filtered data derived from `org_raw.json`, containing the top 11 articles with the highest number of comments (`total_comment`) for each wwek.

- `org_TG.json`  
  Data extracted from `org.json` for the **World** category (*Thế giới*).

- `org_CT.json`  
  Data extracted from `org.json` for the **Domestic News** category (*Thời sự*).
